# BappyGPT


# How to run BappyGPT
## 1. Clone the repository
git clone rep URL

## Navigate to project 
cd BappyGPT

## create virtual environment 
conda create -n bappygpt python = 3.11 -y

## activate virtual environment
conda activate bappygpt

## install requirements
pip install -r requirements.txt

## Run application
python app.py
